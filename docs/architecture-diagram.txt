DETAILED FLOW: WHAT HAPPENS WHEN YOU SEND A MESSAGE
================================================================================


STEP 1: You Type a Message
--------------------------

  +--------+                    +----------+
  |  YOU   | ---- "Find me ---> | WEBSITE  |
  |        |      events in     | :5173    |
  +--------+      Sydney"       +----------+


STEP 2: Website Sends to API
----------------------------

  +----------+                  +---------+
  | WEBSITE  | --- HTTP POST -> |   API   |
  | :5173    |    /send-prompt  | :8000   |
  +----------+                  +---------+


STEP 3: API Signals the Workflow
--------------------------------

  +---------+                   +----------------+
  |   API   | --- Signal -----> | TEMPORAL       |
  | :8000   |   user_prompt     | SERVER :7233   |
  +---------+                   +----------------+


STEP 4: Workflow Activates Worker
---------------------------------

  +----------------+            +--------+
  | TEMPORAL       | -- Task -> | WORKER |
  | SERVER :7233   |            |        |
  +----------------+            +--------+


STEP 5: Worker Calls LLM
------------------------

  +--------+                    +-----------+
  | WORKER | --- API Call ----> |    LLM    |
  |        |    (via Activity)  |  (GPT-4)  |
  +--------+                    +-----------+


STEP 6: LLM Decides What To Do
------------------------------

  +-----------+                 +--------+
  |    LLM    | --- Response -> | WORKER |
  |  (GPT-4)  |    "Use tool:   |        |
  +-----------+     FindEvents" +--------+


STEP 7: Worker Executes Tool
----------------------------

  +--------+                    +-----------+
  | WORKER | --- Execute -----> |   TOOL    |
  |        |    Activity        | FindEvents|
  +--------+                    +-----------+


STEP 8: Results Flow Back
-------------------------

  +-----------+     +--------+     +----------------+     +---------+     +----------+     +--------+
  |   TOOL    | --> | WORKER | --> | TEMPORAL       | --> |   API   | --> | WEBSITE  | --> |  YOU   |
  | FindEvents|     |        |     | SERVER         |     | :8000   |     | :5173    |     |        |
  +-----------+     +--------+     +----------------+     +---------+     +----------+     +--------+
                                          |
                                          v
                                   +-------------+
                                   | Saved in    |
                                   | Event       |
                                   | History     |
                                   +-------------+
